## 0. 主張

**固定 `k×ATR` 移動停損的問題不在於 `k` 選錯,而在於它的出場判準只用了一個對「趨勢是否仍在持續」不充分的統計量。** 本提案改用平滑趨勢狀態空間模型的 Kalman 濾波,以斜率後驗的符號作為出場條件。

**這是一個機制上的不同主張,不是同一機制換數字** —— 這個區分是本提案能否成立的關鍵,第 4 節專門處理。

## 1. 為什麼調 `k` 解決不了:一個閉式論證

設持倉期間對數價格為帶漂移的隨機漫步 `dX = μ dt + σ dW`。移動停損等價於一個雙邊出場問題:先觸及回撤 `D` 還是先賺到 `G`。由賭徒破產問題的閉式解:

```
P(先跌 D | 而非先漲 G) = (e^{2μG/σ²} − 1) / (e^{2μ(G+D)/σ²} − 1)
```

`k×ATR` 停損令 `D = k·ATR ≈ k·σ_day`。代入後,**停損機率只依賴無因次量 `2k·(μ/σ)`** —— 也就是說,`k` 與趨勢的日 Sharpe 只以乘積形式進入。

用策略一的實測值反推日 Sharpe:`μ/σ = SR_trade / √(平均持倉天數) = 0.1723/√14.24 = 0.0457`。取 `σ_day = 4%`:

| `k` | 回撤容忍 `D` | **P(先被停損,而非先賺到 30%)** |
|---|---|---|
| 2.0 | 8% | 71.2% |
| **3.0**(策略一) | 12% | **61.1%** |
| 4.0 | 16% | 52.9% |
| 6.0 | 24% | 40.5% |

**要把提前出場機率壓到 40%,需要容忍 24% 的回撤** —— 那已經逼近 [`scope.md`](../scope.md) 的整體最大回撤上限,單筆交易不可能這樣配置。

**這是結構性的:加密貨幣的日 `μ/σ ≈ 0.046` 太小,任何可接受的 `k` 都落在這條曲線的高停損機率段。調 `k` 只是沿同一條曲線滑動,換不到質變。**

### 1.1 更根本的問題:回撤不是充分統計量

固定停損的出場決策**只用「距峰值的回撤」一個數字**。但對「趨勢是否仍在持續」這個推論問題,兩條回撤幅度相同、路徑平滑度不同的序列,提供的證據強度完全不同 —— 一條是穩定上升中的一次急跌,另一條是早已橫盤震盪後的又一次下探。**固定停損分不出這兩者,因為它丟掉了路徑資訊。**

這才是要修的地方。

## 2. 提議的演算法

### 2.1 模型

把對數價格建模為平滑趨勢(local linear trend,Harvey 的 structural time series):

```
y_t = L_t + ε_t,          ε_t ~ N(0, σ_v²)     觀測方程
L_t = L_{t−1} + μ_{t−1}                        水準
μ_t = μ_{t−1} + η_t,      η_t ~ N(0, σ_μ²)     斜率(趨勢)
```

令 `σ_L² = 0`(水準只透過斜率移動),模型只剩**一個**結構參數:訊噪比 `q = σ_μ²/σ_v²`。

Kalman 濾波對此模型是**最適線性濾波器**,逐期給出斜率後驗均值 `μ̂_t` 與變異數 `P_t^{(22)}`,而且**只用 `y_1..y_t`**,沒有未來資訊。

### 2.2 出場規則

```
出場  ⟺  P(μ_t > 0 | y_1..y_t) < θ
      ⟺  μ̂_t / √P_t^{(22)} < Φ⁻¹(θ)
```

**取 `θ = 0.5`**,規則化簡為 **`μ̂_t < 0`**。理由有二,都與過擬合防線直接相關:

1. **不引入額外自由參數。** 任何 `θ ≠ 0.5` 都需要再挑一個數字,而我們沒有可辯護的先驗能決定它該是 0.4 還是 0.3。
2. **尺度不變。** `μ̂_t < 0` 完全不依賴 `σ_v` 的估計 —— **少一個要從資料估計的量,就少一份過擬合的可能。**

### 2.3 唯一的參數,取自已定案的數字

平滑趨勢模型等價於 HP 濾波,且 `λ = 1/q`。HP 增益為 1/2 的截止週期 `p` 滿足:

```
λ = 1 / (16 · sin⁴(π/p))
```

因此 `q` 可由「趨勢的時間尺度 `p`」直接指定,**不需要從資料估計**:

| `p`(天) | `λ` | `q` |
|---|---|---|
| 30 | 523.5 | 1.91e−03 |
| **45** | **2639.6** | **3.79e−04** |
| 60 | 8330.7 | 1.20e−04 |
| 90 | 42131.2 | 2.37e−05 |

**取 `p = 45` 天,因為 [`risk-policy.md`](../risk-policy.md) 2.3 節的 45 天 time-stop 是規劃期就定案的數字,遠早於取得任何資料。**

這一點很重要:它意味著這個出場機制的**唯一參數不是我們現在挑的**,而是繼承自一個已經在 git 歷史裡、時間戳早於資料取得日的決定。

> ⚠️ 但要誠實說:45 天當初是作為 **time-stop** 定的,不是作為**濾波截止週期**定的。兩者都是「這個策略認為趨勢的時間尺度大約多長」的表述,借用是合理的,**但這是我方的類比,不是原始決策的本意**。若審閱者認為這個借用太寬鬆,替代方案是把 `p` 也列入掃描,代價是 `N` 增加。

## 4. ⚠️ 最難的部分:`N` 的誠實會計

### 4.1 這算不算策略一的變體

[`post-mortem-strategy-1.md`](../post-mortem-strategy-1.md) 4.1 節訂了界線:「換個 `k` 值不是新假說,是策略一的第 6 個參數點」。

**本提案主張它跨過了那條界線**,理由:

| | 策略一 | 本提案 |
|---|---|---|
| 出場判準的輸入 | 距峰值回撤(1 個數字) | 整條路徑的濾波後斜率 |
| 判準的性質 | 固定波動度倍數 | 斜率後驗的符號(統計推論) |
| 參數 | `k`(倍數) | `p`(時間尺度),繼承自既有文件 |

第 1 節證明了兩者**不是同一條曲線上的兩個點** —— 調 `k` 沿賭徒破產曲線滑動,而換判準是改變決策所用的統計量本身。

**但這個主張應該由專案負責人裁決,不是由提出者自我認證。** 我把論證放在這裡,判斷權留給審閱。

### 4.2 更麻煩的問題:診斷來自資料

即使接受 4.1,仍有一個無法迴避的事實:**「出場機制是瓶頸」這個洞察,是看過策略一在這份資料上的結果之後才得到的。**

這意味著即使 `N` 名義上只有 1(單一參數、單一機制),**實質的研究者自由度大於 1**。誠實的做法是把門檻算在保守的 `N` 上:

門檻(`SR_trade`,偏度/峰度取策略一實測的 0.939/3.448):

| `N` 的認定 | `n_eff`=40 | `n_eff`=55 | `n_eff`=70 |
|---|---|---|---|
| `N=1`(只算新機制,樂觀) | 0.2373 | 0.2044 | 0.1825 |
| `N=6`(策略一 5 點 + 本機制) | 0.4276 | 0.3675 | 0.3278 |
| **`N=10`(含診斷自由度,建議)** | **0.4685** | **0.4024** | **0.3588** |
| `N=20`(很保守) | 0.5174 | 0.4441 | 0.3957 |

> 對照:策略一實測 `SR_trade = 0.1723`,`n_eff = 70.5`。

**建議採 `N=10`。** 它沒有精確的推導 —— 研究者自由度本來就不可精確計數 —— 但它明確地把「我們看過資料了」這件事定價,而不是假裝沒發生。**寧可保守。**

### 4.3 更乾淨的替代:換資料

真正消除 4.2 問題的做法是**在沒看過的資料上驗證**:

- 其他流動性足夠的幣安現貨交易對(如 SOL/USDT、BNB/USDT)
- 代價:它們的上市時間較短,樣本量下降;且與 BTC/ETH 高度相關,不是完全獨立的證據

**建議兩者並行:主檢定用 BTC/ETH 但採 `N=10` 的保守門檻,並把其他交易對的結果列為佐證(不列入主判定)。** 這樣既不假裝資料是乾淨的,也不浪費已有的 9 年樣本。

## 5. 已知的代價與風險

1. **偵測延遲。** 用整條路徑做推論必然比「碰到回撤就出場」慢(測試量到反轉後 60 根內)。**這是設計的取捨,不是缺陷** —— 但它意味著單筆最大不利偏移(MAE)會比策略一大,[`risk-policy.md`](../risk-policy.md) 的部位大小公式需要重新檢查是否仍能守住回撤上限。
2. **沒有硬性下檔保護。** 斜率轉負可能來得比崩盤慢。**災難後備停損必須保留**,而且可能需要比 −25% 更緊 —— 這是核心治理數字,需要另走 CP 流程。
3. **模型設定風險。** 平滑趨勢模型假設斜率是隨機漫步。若真實的趨勢結束是跳躍式的(加密市場很可能如此),這個模型會系統性地反應太慢。**這是本提案最可能失敗的方式**,且它在合成資料上測不出來。
4. **交易頻率會下降。** 持倉更長 → 交易更少 → `n_eff` 更低 → 門檻更高。第 4.2 節的表格已把這個效應納入。

## 7. 誠實揭露

- **第 1 節的賭徒破產計算把持倉期間的 `μ`、`σ` 當成常數**,真實市場兩者都隨時間變動。這個計算的用途是說明**量級與結構**(「`k` 只以 `2k·μ/σ` 進入」),不是精確預測停損機率。
- **`σ_day = 4%` 是我方對 BTC 日波動的粗估**,未由本專案資料實測(實測會消耗預先登錄額度)。結論對這個值不敏感 —— 改成 3% 或 5%,`k` 之間的相對關係不變。
- **Harvey 的 structural time series、HP 濾波與狀態空間的等價關係、Ravn–Uhlig 的頻率調整**,我方均未取得原典,理解來自公式結構本身(見 [`reading-list.md`](../reading-list.md) 第 8 節的一貫揭露)。`λ = 1/(16 sin⁴(π/p))` 這條關係**應在採納前核實**。
- **本提案由 quant-mathematician 提出,尚未經 backtest-analyst、risk-manager、quant-strategist 審閱。** 第 5 節的風險 1 與 2 直接落在 risk-manager 的職責範圍。
