## 0. 一句話

**σ_target 的凸性 bug 是真的,但「顯而易見的修法」(用本次評估樣本反推校準常數)在統計性質上幾乎等同於文件已明文禁止的事後調參,只是換了一層數學包裝 —— 真正乾淨的修正需要用不重疊的樣本估計凸性修正係數,而這會引入新的假設與參數,不是零代價的 bug 修正。**

## 1. 問題重述

[`strategy-4-results.md`](../strategy-4-results.md) 第 3.1 節已記錄:設計意圖是平均曝險 = `w0 = 0.1661`(MDD 上限 30% 依對數空間正確換算的固定曝險,推導見 [`run-1-invalid.md`](../strategy-4-run-1-invalid.md) 第 1 節)。原推導假設:

```
E[σ_target / σ̂_t] ≈ σ_target / E[σ̂_t]        ← 錯,忽略了 1/x 是凸函數
```

正確關係由 Jensen 不等式:`E[1/σ̂_t] ≥ 1/E[σ̂_t]`,等號僅在 `σ̂_t` 無變異時成立。實測 `E[1/σ] = 1.8286 > 1/E[σ] = 1.5332`,導致 `σ_target = 0.123` 時實現平均曝險 `0.2306`,比設計目標高 39%。

**[`strategy-4-results.md`](../strategy-4-results.md) 第 3.2 節已明確標記:「把 σ_target 降到約 0.089(= 0.123 × 0.1661/0.2306)…… 這是看到結果之後調參數,絕對不能做。」** 本提案的目的,就是在「不能直接這樣做」的前提下,誠實分析有沒有乾淨的替代路徑。

## 2. 三個修正選項(quant-mathematician 分析)

### 選項 A:樣本內反推 `σ_target = w0 / E[1/σ̂]`

用本次回測全樣本量出的 `E[1/σ̂] = 1.8286`,反推 `σ_target = 0.1661 / 1.8286 ≈ 0.0908`。

**這不是乾淨的 bug 修正,而是包了一層數學包裝的樣本內校準。** 關鍵檢驗:與文件明文禁止的事後倒推比較 —— 禁止的倒推是 `0.123 × (0.1661/0.2306) = 0.0886`,選項 A 是 `0.0908`,**兩者只差 2.4%,且差距全部來自 ramp/clip 的二階效應**,不是來自用了不同資訊 —— **兩者都是同一段被拿來判定 MDD≤30% 的樣本(`n=3270`)的實現統計量的函數。**

選項 A 修正的函數形式是對的(該用 `E[1/σ]` 而非 `1/E[σ]`),但把這個未知母體動差直接用**同一段將被拿來判定的樣本**估計,會讓 `E[exposure]` 在這個樣本上幾乎恆等於 `w0` —— 這是同義反覆(tautological),對其他樣本不成立。**由於 MDD 高度依賴平均曝險,這實質上讓第一層絕對約束的檢定失去獨立性**,統計性質上與被禁止的「調到接近通過為止」是同一類動作。

- (a) 無新自由參數
- (b) **嚴重樣本內校準**(直接用本樣本實現值)
- (c) 應歸類為**新設計決策**,不是 bug 修正 —— 凸性關係修正本身是 bug 修正,但「用哪個樣本估計 `E[1/σ]`」是一個獨立的、原定義未規定的選擇

### 選項 B:解析修正(不吃本樣本實現值)

假設 `ln σ̂_t ~ N(μ, s²)`(已實現波動近似對數常態),則 `E[σ̂]·E[1/σ̂] = exp(s²)` —— 修正係數恆 `≥1`,方向與 Jensen 不等式一致,`s²=0` 時退化為無偏誤。

數學上可行,但代價:
- 新增一個分布假設(對數常態),需要獨立的適合度檢定
- 需要 `s²` 的估計來源 —— **若 `s²` 仍取自本次評估樣本,等於選項 A 換了外衣,一樣有樣本內校準問題;只有當 `s²` 來自與本次 MDD 判定窗口不重疊的資料**(例如已作廢的 run-1 樣本、更早期切分、或獨立幣種)**時,才能真正避免資料窺視。**

- (a) 新增 1 個自由參數(`s²` 或其估計來源)+ 1 個分布假設
- (b) 嚴重程度取決於資料來源 —— 跨樣本估計則輕微/可接受,沿用本樣本則等同選項 A
- (c) **新設計決策**,需計入 `N`

### 選項 C:重新設計曝險規則使其自帶無偏性

例如線上自適應控制(用截至 `t` 的滾動實現平均曝險回饋調整目標),每期只用過去資訊、無前視偏誤,但**無法解決核心問題**:全樣本平均曝險仍會被控制迴路拉向 `w0`,MDD 檢定因此仍近似同義反覆,只是把「一次性用全樣本統計量」換成「連續用截至當下的樣本統計量」,本質相同。若改用解析變換(調和平均、對數空間曝險規則)以求恆無偏,最終仍需回到選項 B 的分布假設才能求出解析常數。

- (a) 至少新增 1-2 個參數(回饋視窗、增益,或分布假設)
- (b) 若用線上回饋則仍隱含樣本內自我校準,嚴重度中高
- (c) **新設計決策**,且鑑於 [`CP-005`](./CP-005-risk-policy-for-always-in-market.md) 3.4 節斜坡吸收態的前例(立意良善的新機制產生未預期行為,見 [`run-1-invalid.md`](../strategy-4-run-1-invalid.md) 第 2 節),額外實作風險高,`N` 成本最大

## 3. 建議(僅供參考,決定權在專案負責人)

quant-mathematician 傾向**選項 B**,但有硬性前提:修正係數(或等價的 `E[1/σ]/E[σ]` 比值)**必須來自與本次 MDD 判定窗口不重疊的資料**(例如已作廢的 run-1 樣本、另一切分區間、或獨立幣種的已實現波動分布),並且要先做對數常態適合度檢定、在看到本次 MDD 結果之前把 `σ_target` 定案封版。

- **選項 A 不建議採用**:數值上(0.0908 vs 被禁止的 0.0886,僅差 2.4%)幾乎等同於文件明文禁止的事後倒推。若專案負責人仍選擇 A,應誠實歸類為「新設計決策」而非「bug 修正」,計入 `N`,並記載這是本專案**第三次**修正 `σ_target` 推導、且每次修正結果都更接近通過的模式的延續([`strategy-4-results.md`](../strategy-4-results.md) 第 7 節已有此警示)。
- **選項 C 不建議作為優先方案**:新增機制與參數最多,且有 [`CP-005`](./CP-005-risk-policy-for-always-in-market.md) 的前車之鑑。

## 6. 時間切分方案(quant-mathematician 設計,2026-08-16)

### 6.1 切分規則與其局限

切分點由「校準精度需求」的公式反推,不是挑選出來讓評估期結果好看的日期:校準期起點固定為資料起點 `2017-11-01`,長度由 `n_eff ≥ 50`(相對誤差 ≈20%)反推 —— `n_eff ≈ L_calib / W`(`W=20`),故 `L_calib ≈ 1000` 交易日(約至 **2020-07-27**)。

**⚠️ 誠實揭露(不可省略):這件事無法做到純粹的預先登錄。** 我方已經看過全樣本的 `E[1/σ] = 1.8286` 與策略四的完整判定結果([`strategy-4-results.md`](../strategy-4-results.md))。任何現在才訂的切分規則都帶著這層污染 —— 能做到的極限是「規則本身不因『哪段結果好看』而調整」,不是「規則完全不受污染」。這一點必須留在紀錄裡,不能包裝成乾淨的預先登錄。

### 6.2 具體方案

| 項目 | 數值 | 依據 |
|---|---|---|
| 校準期 | 2017-11-01 ~ 2020-07-27(約 1000 個交易日) | `n_eff ≥ 50` 精度需求反推,見 6.1 |
| Embargo | 20 個交易日(一個完整 `W` 窗口) | 消除已實現波動滾動窗口在校準/評估邊界的機制性重疊 |
| 評估期 | embargo 結束後 ~ 2026-07-31(約 2250 個交易日) | 用於第一層 MDD 與第二層 Δ 的**正式**判定,取代原本的全樣本 `n=3270` |
| 校準係數 | 校準期內實測 `E[1/σ̂]`(經驗值,不假設對數常態) | 避免額外引入分布假設;若要用 CP-007 第 2 節選項 B 的對數常態解析式,`s²` 同樣只能用校準期資料估計 |
| `σ_target` | `w0 / E[1/σ̂]_校準期` | `w0 = 0.1661`(對數空間正確換算值,見 [`run-1-invalid.md`](../strategy-4-run-1-invalid.md) 第 1 節) |

**已知但無法消除的殘留問題:** embargo 只消除「同一段底層報酬被算兩次」的機制性污染,消除不了已實現波動的長記憶自相關造成的跨邊界相關性 —— 這是單一連續歷史序列的結構性限制,切分手法解決不了。

### 6.3 對第二層檢定力的代價

評估期從 `T≈3270` 天縮到 `T≈2250` 天(約 69%),`Δ` 門檻因此上升約 **21%**(`∝1/√T`);疊加 `N: 13→15` 再約 +3–5%。**合計現行門檻 0.4994 估計上升到約 0.60–0.63(+20~25%)。**

**但這不改變第二層的結論方向:** 實測 `Δ=+0.0318` 只有現行門檻的 6%、`p=0.84`,離顯著非常遠。評估期縮小只會讓門檻更高,**不可能把一個近乎零的效應救成顯著** —— 這個方案只解決第一層 MDD 判定的樣本內校準問題,對第二層「不主張 edge」的結論沒有幫助,也不該被期待有幫助。

### 6.4 `N` 的建議值:**15**

這整套方案(選項 B 本身 + 校準源選擇/時間切分 + embargo 天數 + `n_eff` 精度目標)是一次性綁定的多重新設計決策,建議 `N` 提高到 **15**,並在結果文件上明列:**這是本專案第三次修正 `σ_target` 推導、第四次改動策略四的驗證方法論。** 若重跑後第二層仍不通過,依 CLAUDE.md 預先登錄紀律,**應停止再繼續重新推導 `σ_target`,直接宣告不主張 edge,不得再嘗試第四次修正。**
